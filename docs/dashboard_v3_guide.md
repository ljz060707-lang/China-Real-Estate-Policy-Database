# Dashboard V3 使用指南

普通用户只看到六个一级入口：数据总览、政策中心、自动更新与完整性、数据质量、人工审核、
个人设置。

政策中心以 `v_policy_action_center` 为唯一主数据源。左侧筛选时间、地区、五类动作分类和
关键词；中部显示四项指标、最多两张主图和分页表格；右侧延迟加载原文、动作、证据、版本及
归档信息。未知专题不会回退到全库。

“自动更新与完整性”集中展示运行状态、覆盖矩阵、来源管理和任务报告。历史任务的城市、
省份、主题、来源、分页与候选上限会传入真实执行计划；候选按来源轮转分配，避免前置来源
独占全局配额。

启动：

```powershell
uv run policydb dashboard
```

公开只读模式只允许查询和下载，不允许保存密钥、启动抓取、修改来源或安装计划任务。
