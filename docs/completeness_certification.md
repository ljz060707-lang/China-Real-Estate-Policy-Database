# 完整性认证

`certified_complete` 需要全部必需来源已解决、全年分片覆盖、分页自然耗尽、无上限命中、
无可重试错误、无待抓取、未知日期已清零、归档和正文解析闭环、AI处理与去重路由闭环，
且无跨月、跨城市或来源角色冲突。

`confirmed_zero` 还要求候选确实为零。以下情况永远不能记为零政策：

- 未扫描或仅部分扫描；
- 来源槽位未解决；
- TLS/DNS/超时等网络错误；
- 解析失败；
- 命中候选、页面或抓取上限；
- 分页未自然耗尽；
- 仍有未知日期。

总体完成度取来源、时间、分页、错误闭环、归档及后处理各项百分比的最小值，同时保留全部分项。
