# CRPD 来源准入规则草案

状态：草案，必须经人工确认后才能作为高风险替代规则使用。

本草案只记录待确认事项，不把缺失信息推断为正式来源，也不降低双探测、HTTP 200、官方域名、解析器和分页证据门槛。未确认事项只能进入人工复核队列，不能触发 `strict enable`。

## 必须人工确认的事项

1. 无独立部门官网时，允许哪些市政府或政务服务网替代入口；
2. 政府公报栏目能否跨角色复用，以及复用时需要什么角色证据；
3. 机构撤并、改名或职责转移后的角色归属；
4. 政务服务网是否可作为正式持续采集入口，还是只能作为内容证据；
5. 停更栏目如何处理，是否需要保留历史入口和新的正式替代入口；
6. 一个来源覆盖多个角色的条件，尤其是城市政府、公报和部门角色；
7. 市级与区县级来源的边界，区县来源能否覆盖市级必需槽位；
8. 角色名称、机构名称或域名冲突时的人工裁决标准。

## 当前机器准则

- 只有官方或明确授权的政府来源可以进入正式候选；
- 普通详情页、PDF、新闻或转载页只能保存为内容证据，`entry_eligible=false`；
- 候选存在不等于来源已验证；
- `is_verified`、`verified_candidate_count`、`source_verified` 和 `is_enabled` 只能由现有探测、验证和严格启用流程产生；
- 每个严格通过候选必须有两次独立真实探测、HTTP 200、直连路线、可复用栏目入口、解析器和分页证据；
- 任何角色不明确、城市不明确、替代关系不明确的记录进入人工复核，不自动接受。
